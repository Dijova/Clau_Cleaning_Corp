# Clau Cleaning Corp — website

Static, bilingual (EN default, ES at `/es/`) website for Clau Cleaning Corp, Dracut, MA.
Built on the same layout as the SGM Clean Solutions site, plus a project gallery, client
section, process, service area and FAQ.

## Structure

```
index.html            English home page (source of truth)
es/index.html         Spanish home page, GENERATED by tools/build-es.mjs (do not edit by hand)
services/<slug>/      English service pages, GENERATED by tools/build-services.mjs
es/services/<slug>/   Spanish service pages, GENERATED by tools/build-services.mjs
gallery/, clients/    Gallery and Our Clients pages, GENERATED by tools/build-pages.mjs (also under es/)
service-areas/<city>/ One page per city (26 in MA and NH), GENERATED by tools/build-pages.mjs (also under es/)
404.html, .htaccess   Not-found page and Apache settings (security headers, caching, compression)
favicon.ico           Classic favicon (plus PNG icons in assets/img/)
privacy.html          Privacy policy (EN + ES)
assets/css/styles.css Brand tokens at the top (:root) and all styles
assets/js/main.js     Menu, gallery filter + lightbox, secure quote form
assets/js/gallery-motion.js  GSAP gallery motion: animated filter (Flip), before/after slider (Draggable),
                      scroll reveal (ScrollTrigger), lightbox zoom. Loaded only on pages with a gallery
assets/js/vendor/gsap/  Self-hosted GSAP 3.15.1 (the CSP only allows scripts from the site itself)
assets/js/analytics.js  Google Analytics 4 loader (paste the G- ID to turn it on)
assets/fonts/         Self-hosted Comfortaa + Inter
assets/img/           Logo family (generated), favicon, OG image
backend/              Google Apps Script for the form (see backend/README.md)
tools/es.json         Spanish translations, keyed by data-i18n attributes
tools/services-data.mjs  Service page texts (English + Spanish), based on the commercial service agreement
tools/locations-data.mjs Cities, clients (with their locations) and gallery items
tools/home-blocks.mjs    Home page parts filled from the data (<!-- block:name --> markers in index.html)
assets/img/clients/   Client logos: <slug>.png|svg|webp|jpg (slugs in locations-data.mjs), picked up by the build
assets/img/gallery/, assets/video/  Your own gallery photos and videos (add them to GALLERY in locations-data.mjs)
mockup/               Client presentation (mockup/index.html is self-contained)
social/               Facebook + Instagram kit: src/assets.html (editable), export/ (PNG, upload-ready),
                      mockup/index.html (profiles mockup + copy + content plan)
robots.txt, sitemap.xml, site.webmanifest
```

## Publish

The site is static, so any host works. With **GitHub Pages**: repository **Settings → Pages →
Build and deployment → Deploy from a branch → `main` / `(root)`**. Once `claucleaningcorp.com`
is registered, add it under **Custom domain** and point the domain's DNS to GitHub Pages.
`.nojekyll` makes Pages serve the files exactly as they are.

## Workflow

```bash
npm install          # once (cheerio, used by the build)
npm run build        # regenerate the service pages, sitemap.xml and es/index.html
npm run serve        # preview at http://localhost:8080
node tools/build-logo.mjs     # regenerate the logo SVGs
node tools/build-mockup.mjs   # rebuild the client mockup from mockup/screens/*.jpg
node tools/build-social.mjs   # export social images from social/src/assets.html
node tools/build-social-mockup.mjs  # rebuild social/mockup/index.html
```

To add translatable text: put `data-i18n="key"` (text), `data-i18n-html="key"` (with markup) or
`data-i18n-attr="attr:key"` on the element in `index.html`, add the key to `tools/es.json`,
then `npm run build`. The build fails if a Spanish key is missing.

## SEO

- One indexable page per service in English and Spanish, each with its own title, description,
  canonical, hreflang, Open Graph/Twitter tags and `Service`, `BreadcrumbList` and `FAQPage`
  structured data. Home cards and footer link to them.
- `LocalBusiness` structured data with Massachusetts and New Hampshire (plus main cities) as service
  area, map link, social profiles and every service with its URL.
- `sitemap.xml` (generated with all pages and their language alternates), `robots.txt`, `404.html`.
- To edit a service page, change `tools/services-data.mjs` and run `npm run build`.
- Every page's structured data carries the business name, phone and address (`BUSINESS` in
  `tools/layout.mjs`), since Google does not join `@id` references across pages.
- Share images: `assets/img/og/<photo>.jpg` (1200x630 JPG copies of the `svc-*.webp` photos) are used
  as `og:image` when they exist; otherwise the branded `og-image.jpg`. For a new service photo, make
  its copy, e.g. `convert assets/img/gallery/svc-x.webp -resize 1200x630^ -gravity center -extent 1200x630 -quality 82 assets/img/og/svc-x.jpg`.
- `.htaccess` has a commented https + no-www redirect: uncomment it once SSL is active on the host.

## Before going live

1. **Form**: deploy `backend/Code.gs` and paste the URL in `FORM_ENDPOINT` (`assets/js/main.js`).
2. **Logo**: `assets/img/logo*.svg` and `favicon.svg` are vector recreations of the original logo,
   generated by `node tools/build-logo.mjs` (Comfortaa typeface, brand greens). If the company has
   the original artwork file, compare and adjust. Colors live at the top of `styles.css`.
3. **Photos**: the gallery, city pages and 6 service pages (commercial, medical office, floor care, office,
   deep cleaning, janitorial contracts) use the company's own photos and videos (`assets/img/gallery/`,
   `assets/video/`). Carpet, laboratory, car dealership, church, school and disinfection pages still use
   Pexels photos: replace `image:` in `tools/services-data.mjs` with `own('<file>')` once there are photos.
   New photos: WebP, 720x1280 for the gallery, 1200x800 for service pages; videos MP4 H.264, 720p, muted.
4. **Clients**: logos are in `assets/img/clients/<slug>.webp` (all 11 clients). A new client without a logo
   shows a monogram until its file is added.
5. **Form backend**: the quote form has new service values (`commercial`, `laboratory`, `floor`, `dealership`,
   `church`). Redeploy `backend/Code.gs` so the Apps Script accepts them.
6. **WhatsApp / Instagram**: WhatsApp links use +1 978-328-2406; confirm it is the WhatsApp number.
   Instagram handle `claucleaningcorp` is a placeholder; confirm the real URL (index.html
   and the JSON-LD `sameAs`).
7. **Domain**: canonical/hreflang/OG URLs, `sitemap.xml` and `robots.txt` use `https://claucleaningcorp.com/`.
   Change them if the site goes live on another domain.
8. **Analytics**: create a GA4 property and paste its Measurement ID in `assets/js/analytics.js`.
   Calls, WhatsApp clicks and sent quotes are tracked as events.
9. **SEO**: create/verify the Google Business Profile with the same name, address and phone (NAP),
   then submit `https://claucleaningcorp.com/sitemap.xml` in Google Search Console.
