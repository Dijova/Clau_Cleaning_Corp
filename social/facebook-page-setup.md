# Facebook Page setup — Clau Cleaning Corp

Copy-ready text and settings for the business Page. Images are in `social/export/`.

## 1. Profile and Page

- **Personal profile:** the owner (for example, Claudia) uses her own personal Facebook profile.
  Facebook only allows personal profiles for real people, and a business run as a profile can be
  disabled. The personal profile is just the admin; customers never see it.
- **Business Page:** create it from that profile (Menu → Pages → Create new Page). The Page is
  what customers follow, message and review, and it is required for ads.
- **Ads:** in Meta Business Suite (business.facebook.com), create a business portfolio, add the Page,
  create an ad account and connect WhatsApp (+1 978-328-2406). Add a second trusted admin and turn
  on two-factor authentication for every admin.
